# Practicus 1.0.0

Первый рабочий выпуск системы сдачи практических работ. Интерфейс размещается на GitHub Pages; Apps Script, Sheets и закрытый Drive принадлежат одному выделенному Google-аккаунту.

- Кабинеты студента, преподавателя и администратора; задания, сдачи, оценки, доработка, группы, квоты и аудит.
- Ежедневное закрытое резервирование метаданных с SHA256, хранением последних семи успешных снимков и отображением состояния в админке.
- Восстановление в отдельную таблицу с проверкой схемы, сохранением оценок и сбросом сессий. Рабочая база автоматически не заменяется; известные удаления не оживляют файлы.
- Управляемый выпуск: изменения main не обновляют рабочий сайт. Перед публикацией тега проверяются версия и отпечаток Apps Script.
- Готовые архивы Apps Script и интерфейса, release manifest и SHA256SUMS.

**Установка обновления:** сначала замените четыре файла Apps Script из этого выпуска, установите FILE_UPLOADS_ENABLED=true, выполните runInitialSetup и опубликуйте New version. Затем запустите workflow Verify and release Practicus с release_ref=v1.0.0 и deploy=true. Подробности — docs/RELEASE.md.

Проверки загрузок и нагрузочные испытания исключены по решению владельца. Производительность 25 МиБ / 30 пользователей не объявляется измеренной. Проверка версии при публикации не передаёт учебные файлы. Новые Google-backup/restore требуют установки этого кода владельцем; проверены модели и контрольные сценарии, а не ваша рабочая таблица.
