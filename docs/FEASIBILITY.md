# Решение о файловых испытаниях

При подготовке рабочего выпуска владелец сообщил: **«Проверка загрузок не нужна.»** Это указание заменяет прежнее требование о блокировке релиза до файлового прототипа.

Проверки настоящих загрузок/скачиваний и нагрузочные испытания исключены из этой подготовки. Учётные записи или Google-пароли для них не запрашиваются. Выпуск не заявляет измеренный результат для 25 МиБ, 30 клиентов или загрузки за 120 секунд. Эти значения остаются проектными лимитами; ограничения бесплатного Google runtime сохраняются.

Обычные локальные регрессионные тесты бизнес-правил, прав доступа, размеров и обработки ошибок остаются частью CI и не обращаются к настоящему Drive. В браузерной проверке этого выпуска сценарий отправки файлов пропущен.

Приём файлов управляется **FILE_UPLOADS_ENABLED=true/false**. Это настройка эксплуатации и не признак успешной приёмки транспорта. Старый FILE_TRANSPORT_VERIFIED читается только при отсутствии нового свойства для совместимости со старой установкой.

Проверка соответствия версии Apps Script при выпуске Pages читает только публичный health-ответ. Она не отправляет и не скачивает учебные файлы, не выполняет нагрузку и не проверяет учётные данные.

Приватная модель доступа остаётся обязательной частью реализации: публичные Drive-ссылки или передача Google-токенов клиенту не используются.
