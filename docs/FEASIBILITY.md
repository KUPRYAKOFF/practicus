# Протокол файлового транспорта — НЕ ВЫПОЛНЕН В GOOGLE

## Текущий результат

Локально проверены бизнес-правила, ошибки сохранения и UI. Живых адреса Apps Script, OAuth второго аккаунта и тестовой папки не было; реальные 25 МиБ и 30 пользователей **не проверялись**. Значение `FILE_TRANSPORT_VERIFIED` по умолчанию false. Реальные студент/преподаватель не могут загружать файлы. Администратору доступен отдельный тест `kind=spike`, скачивание его файлов доступно только администратору.

## Обязательные испытания

Тестировать на отдельной БД/папке и трёх тестовых аккаунтах. Нужен также второй студент чужой группы и второй преподаватель для проверки отказов. Кэш/Google-сессия редактора не должны маскировать необходимость Google-входа.

Для каждого опыта записать: дата, версия commit/GAS deployment, браузер/версия, тип сети, число клиентов, состав и точные байты, время начала, время успешного ответа, время скачивания, SHA256 исходника и скачанного файла, результат и ошибка. Запись «не проверено» нельзя заменять предположением.

## Как испытывать

1. В настройках администратора нажмите «Проверить Drive», затем «Тестовая загрузка».
2. Подготовьте разрешённые файлы нужных размеров. Для точного TXT на 25 МиБ можно создать файл из байтов ASCII `A`: нулевые байты TXT отклоняются.
3. Время UI включает резерв, отправку, проверки и сохранение. Скачайте результат. Сравните SHA256 на своём компьютере, а не только наличие файла в папке.
4. Для проверки student/teacher разрешений используйте отдельное тестовое развёртывание. После первого успешного admin-теста временно включите `FILE_TRANSPORT_VERIFIED=true` **только на тестовом проекте**, проведите полный протокол и выключите при любом сбое. Рабочий проект до приёмки остаётся закрыт для загрузок.
5. Для 30 клиентов нужны 30 независимых браузерных контекстов/сессий. Начинайте с 1, затем 5, 10, 30. Испытание без живых студентов. Зафиксируйте результаты каждого, ошибки Apps Script concurrency, `LockService`, UrlFetch и квоты Google.
6. Для разрыва связи используйте DevTools Offline. После восстановления проверьте состояние операции до нового beginUpload. Проверьте очистку неактуальных файлов и расчёт квоты.
7. Только после всего протокола включите `FILE_TRANSPORT_VERIFIED=true` на рабочем проекте.

## Если транспорт не проходит

Сначала проверить меньший `FILE_LIMIT_BYTES`, повторить протокол с новым лимитом и согласовать результат. Платный сервер не добавляется. Публичные ссылки и выдача Google-токена клиенту не применяются. Отдельный бесплатный прокси возможен только как явно согласованное изменение архитектуры; в этой версии его нет.

Google меняет квоты и условия бесплатных услуг. Технически бесплатная схема не означает гарантированную пропускную способность. При недостаточности бесплатных лимитов честный результат этапа — уменьшенный подтверждённый лимит или остановка рабочих загрузок.
