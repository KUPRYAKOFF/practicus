# Согласованные правила

Эта версия учитывает ответы пользователя после исходного ТЗ от 21.11.2026. При расхождении действуют эти уточнения. Последнее изменение: пользователь объединил Apps Script, Sheets и Drive в одном новом выделенном аккаунте; первоначальная схема двух аккаунтов отменена.

| Вопрос | Решение |
|---|---|
| Стоимость | Полностью бесплатно. При невозможности стабильной передачи допускается уменьшить лимит после фиксации результатов |
| Размещение | Весь пользовательский интерфейс — GitHub Pages в KUPRYAKOFF/practicus |
| Сервер и метаданные | Apps Script и Sheets в отдельном выделенном Google-аккаунте приложения; личный аккаунт пользователя не участвует |
| Хранилище файлов | Drive того же выделенного аккаунта, что Apps Script и Sheets |
| Нагрузка | До 30 одновременных пользователей; целевое время загрузки до 120 секунд |
| Комплект | До 25 файлов, суммарно до 25 МиБ (26 214 400 байт); такой же суммарный лимит на материалы задания |
| Своевременность | Сервер фиксирует начало загрузки, а не завершение сохранения |
| Доработка | Разрешена после дедлайна, даже при политике закрытого приёма; опоздание отмечается |
| Принятая работа | Новая сдача закрыта до возврата на доработку |
| Оценивание | Оценка 2–5 и комментарий необязательны. При доработке текущая оценка сбрасывается, прежняя остаётся в аудите |
| Перевод студента | Свои сдачи и оценки остаются доступны, пока задание опубликовано; преподаватель не видит работы чужих текущих групп |
| Отзыв доступа преподавателя | Немедленно закрывает доступ к сдачам и файлам отозванных групп, включая исторические |
| Новые члены группы | Получают ранее опубликованные задания текущей аудитории |
| Исключение из аудитории | Сохраняет доступ к собственным сдачам и оценкам; скрывает материалы задания и запрещает новую сдачу |
| Архив | Студент видит только оценку и идентифицирующее название задания, без файлов и комментария |
| Возврат в черновик | Полностью скрывает задание от студента, включая результаты |
| Замена | Новый комплект целиком заменяет предыдущий; при ошибке старая сдача сохраняется |
| Квоты | Студент 125 МиБ, преподаватель 250 МиБ; администратор может менять |
| Освобождение квоты | Студент удаляет файлы старых сдач; можно удалить и находящиеся на проверке |
| Оценки при удалении | Сохраняются вместе с записью сдачи |
| Срок хранения | Каждый файл — два календарных года от времени его создания в Drive. Новый файл при пересдаче получает новый срок |
| Автоудаление | Ежечасная очистка после истечения срока; оценка не удаляется |
| Пользователи | Базовое управление через интерфейс обязательно, дополнительно импорт из Sheets |
| Оформление | Нейтральный стиль Practicus. Официальные логотип и фирменные параметры будут позже |

Время храним UTC, показываем Asia/Irkutsk. Сессии действуют 8 часов. Действия с оценками и правами журналируются. Email-уведомления, чат, регистрация, восстановление пароля по почте не входят в первую версию.

Техническое определение начала: успешное создание серверного резерва непосредственно перед отправкой формы с файлами. Оно не равно точному моменту первого сетевого байта. Резерв действителен 120 секунд; фиктивно открыть загрузку и переслать её спустя длительное время нельзя. При обрыве и новой операции после дедлайна учитывается новое серверное время начала.
